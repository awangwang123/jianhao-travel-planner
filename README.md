# 见好 · 旅行规划器（jianhao-travel-planner）v1.1 — 使用说明

> 2026-09-21 从作者本体 v3.26 派生；**v1.1（2026-09-26）对齐作者本体 v3.34**。打开 `SKILL.md` 可见完整工作流与版本演进记录（每条规矩后面的翻车实录是精华，建议通读）。

## 这是什么

一套「出行路书」工作流：你说"想出去玩"，它按固定流程采集需求 → 联网实查 → 产出**路书**（md 事实源 + 单文件 HTML 双版本：本地完整版断网可开 + 瘦身在线版一键部署）+ **美食情报卡**（按城市持续追加的数据资产）。

## 体系亮点（功能与效果）

- 🔍 **信息可核验**：关键信息联网实查带来源，未核实的明确标注；票价带查询时戳，出发前按当日预报终判
- 🚫 **交付更干净**：对外内容自动做敏感信息检查，零残留才出门
- 🍜 **吃饭有章法**：逐日三餐机械核对不缺项；私藏店/必吃店/顺路店各归各位，附「先看差评再决定」方法论
- 🖼 **配图更真实**：古画、工地照、过度滤镜三类假图直接跳过，每张逐张人工核验
- 🗺 **导览图更专业**：指北针、地标小图标、行程动线编号六要素齐备，手机上看也清楚
- 🏅 **推荐不重复**：私藏推荐集中一个板块，正文清单不掺私货，照抄照选两相宜
- ✍️ **改稿不丢改动**：路线书与底稿自动同步，反复修改也不怕
- 🌐 **一键上网**：瘦身网页版一键部署，手机电脑点开即看，打开速度快一倍

## 版本哲学：两天 7 版，每一版都是被骂出来的

- 做了 8 份路书，才发现模板里没有「住宿」——补上
- 对外稿混进不该有的字眼——脱敏不归零不准交
- 5 天行程没有一天凑齐三顿饭——机械检查一跑就现形
- 导览图没有指北针，配图拿古画冒充地标——挑图先建概念
- 推荐的店散落三处——定死归属
- 成品改了十几轮，底稿一字没动——错误反复复活，立双写制
- 一个称呼改三遍不统一——拍死口径，旧称即违规

一句话：**从「能出攻略」到「错了必有钩子拦」**。这套 skill 值钱的不是规矩，是规矩后面的血案。

## 安装（2 分钟）

解压后你会得到一个 `jianhao-travel-planner` 文件夹（别改名），把它整个放进 skills 目录：

- **全局**（推荐）：`~/.claude/skills/`（Windows 即 `C:\Users\<用户名>\.claude\skills\`）
- **单项目**：`<项目>\.claude\skills\`

装好后的路径应该是 `…/skills/jianhao-travel-planner/SKILL.md`。放对之后，跟 AI 说"周末想去 XX 玩"就会被自动触发。

目录结构（缺一不可）：

```
jianhao-travel-planner/
├── SKILL.md          ← 工作流正本
├── assets/           ← 路书+情报卡两份 HTML 基准骨架
└── tools/            ← consistency.py（骨架校验）+ desource.py（脱敏）
```

> ⚠️ **已有同名包？** 如果 skills 目录里已存在 `jianhao-travel-planner` 文件夹，本包拷入会覆盖它（作者的自用版叫 `travel-planner`，不同名、不受影响）。

## 配图 key（再花 2 分钟）

路书要求"每天都有图"，图源走 Pexels（免费可商用）：

1. pexels.com 免费注册 → 个人设置页申请 API key
2. key 存本机 `.env` 文件（`PEXELS_API_KEY=你的key`）或环境变量
3. 不配图 = 过不了交付自查清单第⑱项

> **不想注册也行**：用你自己的 AI 生图工具产「（示意）」图一样合规——规矩只要求每天配图 + 非实拍标「（示意）」+ 页脚注明来源，AI 生成图在页脚写「AI 生成示意」即可，还省一个外部依赖。

## 第一次使用前

打开 `SKILL.md` 末尾的「用户档案（填空模板）」，复制填写你自己的偏好（出发地/口味/作息/同行者常态），填完这套 skill 就"认识"你了。信源名单不用预置——它会用大众点评+高德+小红书交叉验证，你在旅途中刷到靠谱探店内容可以补进自己的名单。

## 不需要的东西

- 任何平台登录态（抖音/小红书/B站都不需要）
- 付费 API
- 博主白名单（原个人设定已移除）

## 给使用者的最后一句话

这套 skill 值钱的不是规矩，是规矩后面的血案（版本史里的翻车实录）。你第一版路书大概率也会被打回几次——那是正常的，把教训写回"经验沉淀"区，它就会越来越像你。
